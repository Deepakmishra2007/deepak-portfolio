## 🚀 How to Run the Project

This portfolio is built with pure, high-performance **HTML5, CSS3, and JavaScript**. You **do not need Node.js or npm** to run it!

### Option 1: 1-Click Launch (Easiest)
- Double-click [`run.bat`](file:///c:/Users/Deepak/Downloads/Deep%20Portfolio/run.bat) in this folder. It will start the local server and automatically open the website in your browser.

### Option 2: Open in Browser Directly
- Double-click [`index.html`](file:///c:/Users/Deepak/Downloads/Deep%20Portfolio/index.html) or right-click it and select **Open with > Google Chrome / Microsoft Edge**.

### Option 3: Terminal Command
Run either:
```bash
npm start
```
or
```powershell
python -m http.server 5173
```
Then visit: **[http://localhost:5173](http://localhost:5173)**
